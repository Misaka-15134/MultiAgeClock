# Code availability

The R implementation for applying the frozen MultiAgeClock models, together with the required preprocessing and calibration parameters, synthetic examples and usage documentation, is available at [Misaka-15134/MultiAgeClock](https://github.com/Misaka-15134/MultiAgeClock). Pretrained inference weights are distributed with [version 0.1.0](https://github.com/Misaka-15134/MultiAgeClock/releases/tag/v0.1.0). This distribution supports inference for the full clinical, Olink, NMR, integrated, reduced clinical K17 and exploratory clinical K4 models. The code and model assets are available solely for noncommercial scientific research under the [MultiAgeClock Noncommercial Research License 1.0](../LICENSE); commercial use requires separate written permission. Training, hyperparameter optimization, feature selection and participant-level research data are not included.

Use a versioned release link when citing the software used for an analysis. The source repository and model assets must have matching versions.
