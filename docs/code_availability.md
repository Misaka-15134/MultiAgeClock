# Code availability

The R implementation for applying the frozen MultiAgeClock models, together with the required preprocessing and calibration parameters, synthetic examples and usage documentation, is available at https://github.com/Misaka-15134/MultiAgeClock. Pretrained inference weights are distributed as versioned release assets. This distribution supports inference for the full clinical, Olink, NMR, integrated and reduced clinical K17 models. Training, hyperparameter optimization, feature selection and participant-level research data are not included.

Use a versioned release link when citing the software used for an analysis. The source repository and model assets must have matching versions.
